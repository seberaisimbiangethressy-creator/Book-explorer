About Book Explorer

Book Explorer is a capstone project built with HTML, Tailwind CSS, and vanilla JavaScript. It fetches book data from the Open Library API, lets you search by title, and stores your favorites in your browser so they're still there when you come back.

What's inside

  • Responsive layouts that adapt from phones to desktops
  • Async data fetching with loading, empty, and error states
  • ES6 modules for API access, favorites storage, and UI helpers
  • localStorage persistence for your favorite books
